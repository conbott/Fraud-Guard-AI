# FraudGuard AI - Model Registry & Artifacts

This directory houses the versioned model artifacts, evaluation metrics, and champion/candidate lifecycle records.

## Directory Layout
- `champion/`: Active production model artifact (`model.joblib`), pipeline configuration, metadata (`metadata.json`), and schema definitions.
- `candidates/`: Retrained candidate models awaiting gate validation or archived previous models.
- `reports/`: Machine-readable evaluation reports, ROC/PR curves, confusion matrices, and drift audits.

## Artifact Integrity & Security
- Model artifacts are serialized with Joblib and cryptographically hashed (SHA-256 fingerprinting).
- Only artifacts generated by the repository's internal training pipeline are loaded.
- Arbitrary user-uploaded pickle or joblib files are strictly rejected by the model loader.
- Model metadata tracks the feature schema, scikit-learn version, random seed, training timestamp, decision threshold, and performance metrics.
